# 時計と長く続く家族の記録

現実の1分をゲーム内1時間に統一する。365日換算の10年は現実の約60.83日。成長段階は既存のゲーム上の12・24・48時間を維持し、実際の飼育目安とは扱わない。

旧v1〜v11は厳格に検証してからv12へ移行する。既存の年齢・経過tick・名前・ゲージ・履歴の日付・死亡情報を保持し、新しい時計の起点を移行時刻へ置く。移行直後に以前の短い時計を新時計として再計算しない。移行前の原本は自動保存先に別途保持し、設定から書き出せる。

長い不在では既存の鳥の年齢・成長・寿命と現実のお世話期限を進める。新しい来訪・交際・産卵を大量に再生しない。短い不在では通常処理を続ける。病気・けが・3日間の放置など現実の期限は従来通り。

活動中の128羽枠とは別に、旅立った鳥の記録をarchiveへ保存する。親子・名前・お墓・日記からの参照を保持し、再来訪する友達は同じIDで活動枠へ戻す。日常日記は最新240件、重要な家族の出来事はjournalへ継続保存する。保存形式の物理上限は64MBで、無限保存とはしない。旧形式の表示は旧時計の記録と明記し、新しい記録は現実の日付を使う。

会話と撫でる操作は元気100でも可能。会話の返事と反応を残し、お世話報酬は追加しない。家族の節目は日々の交流予算から独立して一度だけ加点する。入居10・つがい30・産卵25・孵化35・成長20 Gems。

死別時は現在のつがいを解除して過去の家族日記を保持する。新しいつがいは相談して承諾した時に成立する。死別から48ゲーム時間、同じ相談を見送ってから168ゲーム時間の間隔は今回採用したゲーム上の調整値。病気・近親・年齢などの既存条件も適用する。けがの相性閾値を60へ見直し、実際の最小相性51.1で成立しなかった経路を解消する。

天敵の説明は実装の定数を参照し、出現3秒後の25%判定とカラス・猛禽5対5を表示する。
