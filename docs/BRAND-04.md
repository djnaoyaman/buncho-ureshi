## 同じ原画からの派生ファイル

`scripts/brand-assets.py`（Python / Pillow）で再作成できます。通常のサイトビルドは確定済みファイルをコピーするだけで、Python や画像生成サービスを呼びません。

- `brand/wordmark-04.webp` — 余白だけをトリミングした範囲 `(345, 125, 1465, 770)`、1120 × 645。WebP quality 92、66,200 bytes。ヘッダー、トップ、工房の保存 PNG が共用します。確定した更新原本からの書き出しでは、文字の打ち直し、鳥の描き直し、色の再設計はしません。
- 各 favicon / Apple / Android アイコン — 原画内の文鳥と止まり木だけをフレーミングし、同じ縦横比で縮小・拡大。長い文字列を小さなアイコンへ詰め込みません。
- Android maskable — マークを中央に収め、高コントラスト部分が直径 80% の安全円内にあることをピクセル検査。
- Safari pinned-tab — 原画の明度しきい値から機械的に作った単色マスク。外部画像への依存がない SVG パスですが、手描きベクター原画ではありません。
- `ogp.png` — 1200 × 630、49,797 bytes。原画の縦横比を保って配置し、決定的な 256 色パレット変換で配信用サイズを抑制。赤いくちばしが残ることを実見。
- `favicon.svg` / `icon-maskable.svg` / `ogp.svg` は同じ派生 PNG を埋め込んだラッパーです。
- 全 16 ファイルのサイズと SHA-256 は `public/brand/manifest.json`。

## 画面・工房

`logoSvg()` は既存呼び出し互換の関数名ですが、返すのはサイズ指定済み `<img>` です。サーバー生成 HTML にも同じロゴを入れ、JavaScript 起動前にも表示します。正式名の代替テキストとメタデータを維持します。常時ふりがな、ゲーム保存、観察記録には変更を加えません。

工房は同じ画像の読み込み・decode を待ってから保存します。読み込めないときはロゴ抜きの PNG を生成せず、理由を表示します。上部のブランド・作品名・作品領域を分け、正方形と縦長の両方で元の写真クレジット領域を保持します。画像をパレット色で塗り替えません。

## 検証の境界
