# 小学生向けのあそびかた

2026-11-11、ユーザーの指定により、短い文・平易な日本語・漢字のふりがなで仕上げる。
現在の5つの入口と3つの折りたたみを維持し、必要なときだけ詳しく読める構成とする。

- Goldはゲームのおこづかいと説明し、家族のお世話→そうじ→受け取りの3つの図で案内。
  家庭で1日30 Gold、日本時間の日付、欠席日の蓄積なし、飼育員・通院との関係を説明する。
- 成長は卵からひな・幼鳥・大人へ進む図。孵化5時間36分、孵化後11時間12分、
  孵化後3日半の目安。幼鳥の意味と、旧い鳥は従来速度を保つことも説明する。
- 閉じた間の成長と、物語を止めていても進む給餌・治療の期限を区別する。
  留守の報告は30分以上・1日1件・最近7日分、日記から再読できると案内する。
- 天敵の合図と帰宅操作は2つの図。カラス6秒、猛禽1分、残り10秒の「今すぐ帰る」を説明。
  元気の減少と事故死を区別し、留守番・ミサゴ・なかよしの例外も保つ。
- メニューの「次のお楽しみ」を、気になることから選べる案内として紹介。
- 元気がいっぱいでも会話・なでる反応は楽しめる説明に修正。
  「ゲージ」「承諾」などは、画面で使う言葉や小学生が読める言葉へ置き換える。

図はHTML/CSSの手順カード。説明を読むだけで通貨・成長・保存が変わらない。
追加フォント・外部画像・新しいボタンやゲームの処理・保存形式は追加しない。

200%文字拡大で読みやすさ・横にはみ出さないこと・再読込を確認する。
