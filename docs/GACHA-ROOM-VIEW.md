# ガチャ画面とおうちの試し置き

2026-11-12、添付引継ぎの4画面を参照し、現行デザイン・3台の原画と機能を保って整理。
比較案A/B/Cを過去に採用済みだったとは扱わず、最新mainへ差分で実装する。

- 入口で選択した台・1回の料金・残高を確認できる。
- 新規結果に現物のお飾りと仕上げ、重複結果に実際の使用額と返却額を表示。
- 結果の操作はスクロールする説明とは別の領域に置く。
- おうちと試し置きはhome-scene.jsの同じ背景出力と既存の家具描画を使用。
- プレビューは実画面の縦横比を保つ小さなコンテナ。トップと同じcover・家具配置規則を共有。
  候補だけを表示時に上書きし、世界・所持品・装着・乱数は変更しない。
- 「これでOK」は既存の装着処理。「やめる」は既存の試着取消。既存の結果→試着の導線を維持。
- 保存形式・料金・確率・解放・重複保証・音と演出の処理は変更しない。

合成保存で背景・家具ID・相対位置の一致、取消時の保存全体の一致、
結果操作の表示範囲、二重消費の防止と既存試着導線を検査する。
戻す場合は表示・共通描画・関連検査だけをrevertし、保存データを巻き戻さない。

## 鳥3種の素材

同じ引継ぎのヒノマルチョウ・マスクフィンチ・ズグロヒワは別件。
同梱されたのは参考コードで、専用の原画・写真・権利情報は含まれていない。
2026-11-12時点の最新mainと取得済みブランチ、保管ファイルの種名・finch名検索でも現物は未回収。
他種の画像を流用したり、新規生成を承認済みと見なしたりして追加を完了させない。
必要なのは各種の専用透過原画、作者・出典・ライセンスを伴う写真、
それぞれの学名・原画の個体条件と承認根拠。これらを回収後に別の変更単位で実装する。
