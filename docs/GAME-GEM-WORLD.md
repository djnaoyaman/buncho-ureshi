# 文鳥ぐらし：Gemと家族の世界

## 保存と報酬
保存v4はv1〜v3の既存残高・全羽・家族・履歴・持ち物を保持して移行。内部の `decor.points` / `lifetimePoints` は互換性のため維持し、画面表記をGemへ統一。
給餌6・なでる5・空ではない会話5 Gem。給餌2時間、なでる／会話1時間の間隔。空入力・未成熟／旅立った鳥の会話では付与しない。ゲームの1時間は現実の1分。購入・広告・課金はない。
満腹の食事（90以上）の後、2時間以降に落としもの。1羽1個・全体12個まで、生成間隔4時間。放置しても罰はなく、自動回収もしない。おうちでタップすると保存トランザクション内で削除し8 Gem。描画時revisionに対して古い操作は付与しない。保存完了前には報酬アニメーションを出さない。減らす動き設定では静的表示。
JSON読込は世界全体のスナップショット復元であり、オンライン残高との合算ではない。実在他ユーザーとの通信・金銭交換はない。

## 操作と見た目
場所の3ボタンと遊びのお飾りアトリエを分離。各9分類には8色×3仕上げの24品を表示し、未入手・解放レベルも見られる。未所持品は見るだけで装備不可。
文鳥は横スワイプと前後ボタンで切り替え、縦スクロールと入力操作を妨げない。下書きは文鳥ごとに保持。家系図は選択した文鳥を中心とする上から下への図で、つがいと血縁の線を区別。全名簿の文字表示も残す。
ゲームだけのしおりメニューへ一般サイトのリンク・共有・出典をまとめ、他ページのヘッダー／フッターは元のまま。

## 素材
`public/game-art/game-title.png` はユーザー指定「おもちの文鳥ぐらし」の生成ロゴ。2026-11-02採用。RGBA2172×724、背景透過を保持。既存サイトロゴと実写図鑑の素材は変更しない。
在庫用9種はコード原生SVGを再描画し、陶器・ガラス・木・葉・紙の形、材質と上位仕上げの象嵌／金彩を表現。既存のシーン家具の配置・描画は維持。

ゲームへ入る時は、採用タイトルの画像読み込み・decode後に画面中央へ2秒表示。内部の場所／パネル切替では繰り返さない。動きを減らす設定では静止表示し、読込失敗や別ページへの移動では残らない。

検査は全件を維持し、DOMを多用するNode検査の同時実行を2プロセスに制限。制限なしのローカル一括実行ではプロセス単位の終了が発生したため、個別合格だけで済ませず、この上限で全件を再検証する。
