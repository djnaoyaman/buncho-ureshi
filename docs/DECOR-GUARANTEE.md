# お飾りガチャの新作確定

同じカテゴリで持っているお飾りが2回続いたら、次のガチャは解放済みの未所持だけから抽選します。新しいお飾りが出ると、そのカテゴリだけ回数が0に戻ります。カテゴリの切り替え、閉じる、保存・再読込で回数を失いません。

1回20 Gems、重複時8 Gems返却、通常の色・仕上げの確率、レベル条件は変更しません。確定時は通常の各アイテムの出現率を未所持だけに絞り、合計100%に正規化します。画面には確定時の仕上げ確率と、色の確率も所持状況で変わることを表示します。

いま解放されている種類をすべて持っているカテゴリはガチャを止め、Gems・乱数・回数を変更しません。次の仕上げが解放されるレベルを案内します。Goldで最後の種類を購入しても同様に止まり、保存した確定回数は次のレベルに持ち越します。

保存版はworld10から11へ更新します。旧データを厳密に検証し、各カテゴリの回数0だけを追加します。encounter12・gardenFriends2は維持し、庭ごとの会話・来訪者・同行設定・進行中の天敵警告は変更しません。旧タブは新しいworld版を拒否し、保存を上書きできません。IndexedDBとロック付きlocalStorageの両方で並行購入を直列化します。
