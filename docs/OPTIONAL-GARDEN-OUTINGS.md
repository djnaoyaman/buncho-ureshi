# 任意の家族同行と親しい友達の来訪

- 新しいゲームでは家族はお留守番。庭の「同行」で「次のおでかけは家族と」をオンにし、最大4羽を選ぶと次回の出発から同行する。
- 同行は出発時に確定する。庭の移動、図鑑、再描画、保存・再読込や設定変更で途中参加・途中離脱しない。帰宅後の次回出発に新しい選択を適用する。
- 毎回の庭への訪問で4羽の友達を抽選し、実際のIDを保存する。亡くなった鳥やおうちへ移った鳥は表示から除くが、同じ訪問中に代わりの鳥を補充・再抽選しない。
- 既存の文鳥は生きた幼鳥・成鳥で、自分のおうちから離れて暮らし、現在の主人公との親しさが65より大きく信頼が50より大きい場合、または既存の庭の親しさが60以上なら抽選対象。子孫も対象で、家系・居住・鳥のIDを変更したり新しく鳥を生成したりしない。
- 図鑑の異種の鳥は、発見済みかつ親しみ60以上なら新しい訪問から庭を問わず再来訪の抽選対象。未発見の地域のお客さまと一緒に抽選する。おうちへの招待条件は100のまま。別の庭で会話中の客やおうちの客は重複させない。

## 天敵

新しいカラス・猛禽の来訪は、主人公が実際に同行するときだけ発生する。他の家族や友達に標的を置き換えない。保存済みの有効な猛禽警告は、元の標的を表示し続け、設定変更では残り時間を消さない。明示的な帰宅・警告の終了・標的の死亡など、既存の正当な終了条件を維持する。代替わりで新しい主人公を途中から強制同行させない。

## 保存互換

worldの版10は維持し、encounterを11から12、gardenFriendsを1から2へ更新する。旧データは厳密に検証してから移行し、選択済みの家族・親しさ・記憶・庭ごとの会話・天敵警告を保持する。旧版の初期値と明示的な同行選択は区別できないため、選択そのものを残したまま次回同行の有効フラグはオフにする。移行中の警告は元の標的を引き続き表示する。旧タブは新しいencounter版を拒否して保存を上書きしない。
