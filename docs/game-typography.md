# おもちの文鳥ぐらし：文字と小さな操作部品

## 方針
既存の OMOCHI POP の丸み、紙色、手描き線を維持する。今回の依頼はフォント方針、ヘッダーの図鑑／帰宅アイコン、庭の鳥図鑑ボタンだけ。画面全体の再設計やゲームルールは変更しない。

- 基本文字：端末の丸ゴシックを優先し、Noto Sans JP/CJK、Yu Gothic、sans-serif の順に代替。外部フォントを追加しないため通信量・初回表示待ちは増やさない。端末ごとに字形は異なる。
- 読み物は 1rem、行間 1.8。操作文字は .875rem、補助文字の基準は .8125rem。CSS変数に集約し、既存画面は無理に一括変更しない。狭い画面で全体を縮小せず、文章は折り返す。
- 見出しは既存の太さ800と字間 .02em を継続。数値、ロゴ、意図のある装飾文字はそのまま。
- 今回は図鑑の説明とヘルプの読み物、入力・操作の字体に適用。個別画面の既存サイズ指定は維持。
- 本と家の既存ピクトグラムを利用。可視の文字は隠すが、読み上げ名・ツールチップ・ネイティブのリンク／ボタンを残す。押せる領域は48×48px。帰宅しない「とじる」は文字表示のまま。
- 庭の鳥図鑑ボタンは「庭の鳥」「図鑑」の2行で縦横中央揃え。読み上げ名は分断しない。

## 確認範囲
Node/HappyDOMで帰宅、図鑑遷移、アクセス可能な名前、画面ルート復帰、CSSのスコープを検査。実ブラウザ操作は依頼に従い行わない。iPhone実機の字形・拡大表示・折返し・画面上の重なりは未確認であり、DOM検査を視覚検査と称さない。
