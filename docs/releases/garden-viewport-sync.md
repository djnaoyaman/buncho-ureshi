# 庭の回転直後のviewport同期

基点: 60f108cd574d7f0f7b258e03400b806bc9a5bcc8 (#253)。

現行WebKitで横向きのvisualViewportは390pxへ変わっても、通知前のCSS高さが844pxに残り、鳥の中心が画面外になる移行を確認した。初回本番スモークの単発失敗は同じ瞬間の座標証拠がなく、原因同一とは断定しない。

対応ブラウザの通常画面では高さを100dvhにする。レイアウト自身が回転に追従するため非同期resize通知まで旧pixel高さを保持しない。キーボードでvisualViewportが狭まる場合、旧ブラウザ、拡大表示、offsetとサイト復帰は既存処理を維持。鳥のruntime・地形・保存・得点・RNG・BGM・素材は変更しない。

検査ではshellの実resize通知だけを保留し、画面高さ・鳥の中心hit・実クリックで同じ個体のdialogを確認。旧pixel高さの対照では844pxと画面外hitを検出する。同じdecode完了時点の座標を取得し、hitが成功するまで待つ処理にはしない。通常・密集・先行庭・非対象庭と既存の軽減/設定/保存/BGM検査を維持。

100dvh非対応のiOS15系には従来のpixel処理を維持する。現在WebKitの自動検査は実iPhoneの保証ではなく、旧端末の回転問題まで解消したとは主張しない。実機、物理キーボード/ソフトウェアキーボード操作、携帯回線は未検証。

復旧はこのshell変更と対応する保護baselineを通常のレビュー・検査・公開で戻す。保存の巻戻しや庭定義/音源の巻戻しは不要。

PR CI 44647776951 は367/368成功、WebKit kazaguruma 390の旧地形検査で幅/高さ/planeが全て0になった。traceではready/groundedの確認とElementHandle取得が別呼び出しで、後の測定は空のcomputed styleを返した。再描画で切り離された要素を測る競合に対応し、ready判定と現在DOMの座標を同じブラウザ処理で取得する。hit成功まで待たず、44px・元画像・配色・足場・実クリックのassertionを維持。切り離しを再現する対照と、実際の遮蔽物をhit:falseとして返す対照を追加した。これは検査側の同期修正で、鳥の動作や当たり判定を変更しない。
