# 第2回 鳥たちの小さな探検

- 庭の常連文鳥と一度交流すると招待候補に追加。異なる2羽を選び、みずべ・こかげ・はなの3探索先から選択する。
- 各探索先は1保存につき1回。好みの組合せ6通りで発見・記念品が変わる（全18バリエーションのうち、その保存では最大3つ）。全部集める義務はなく、どの選択も報酬は同じ。
- 一度の探検は招待・発見・「おもいでをもちかえる」。実時間待ち・期限・失敗・欠席ペナルティなし。見送りや中断可能。別庭から再開先へ戻れる。
- 完了時2 Gold、参加した庭の常連の親しみ各+1。最大6 Gold、Gems増減なし、家庭の文鳥の体力・食事や野鳥の親しみに影響なし。発見カードは日記に記録し、参加鳥との通常交流にも記憶を反映。
- 完了済み落ち葉イベントの参加者がいる場合、その選択の記憶を開始時に保存し会話に反映。
- 保存v19はv18へ空のexpeditionを追加するだけ。従前保存の移行バックアップは独立保持。報酬・記録・親しみは既存の単一トランザクションで同時保存。world/revisionによる古い操作の拒否と探索先IDによる二重報酬防止。
- 既存の35庭/野鳥出現/天敵/ガチャ/エンディング/音楽/GA設定は変更しない。
- ブラウザ操作は本人が担当。Node、Happy DOMの実ホスト、CSS、保存互換・2タブ競合・繰り返し検査を実施する。実機の見た目・タッチ体感は自動検査では確認していない。

## 手動確認
庭で常連2羽と交流 → 庭右下の探検 → 2羽と探索先を選ぶ → 発見を持ち帰る → 日記で記念品を読む。途中で別の庭へ移動しても「つづきのにわへ」で再開できる。完了後、参加鳥と通常交流すると探検を思い出す。

## 試遊後の改善
- 出発後に2羽の会話を読み、「おとをきく」「よくみる」を選ぶ短い寄り道を追加。正解・不正解や待ち時間はなく、報酬は同一。選択は保存され、中断しても続けられる。
- 既存v19の進行中・完了済み記録はそのまま読める。新しい途中選択は任意フィールドとして追加。旧進行中の探検は従来どおり持ち帰れる。
- 記念品に小さな絵を付け、持ち帰った直後に2羽の反応と取得済み報酬を見せる。次の探検に自動で進まず、日記へ直接開ける。
