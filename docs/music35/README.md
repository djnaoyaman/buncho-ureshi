# 35庭の専用音楽

2026-11-13: 足立区梅島公園の試聴に対する「良いですよ！！ 後の曲もあなたに任せます。」に基づく専用曲接続。

- 庭1は試聴承認されたオリジナル譜面をループ化。庭26・30・35を除く残31庭も固有の旋律、拍子、編成で自作合成し、外部音源サンプルは使用していません。
- 庭26「白樺の赤いしるし」、30「潮風の歌う丘」、35「金いろの高原窓」は既存Work試作。本人が「制作はそのWorkでやったので公開してよいです。」と公開許可。第三者ライセンスの独立確認を意味しません。
- `src/data/garden35-music.js` は音源ハッシュ・ループ範囲・由来を保持。旧12庭のthemeIdを維持し、固定曲選択・音量・OFF設定を保護。
- 4つの共通曲と旧12曲ファイルは削除しません。家族・所持品・通貨・訪問/出会い履歴の保存形式は変更しません。
- 音源は選択された1曲だけ取得・デコード。連続移動の古い要求を無効化、デコードは直列、キャッシュは1曲のみ。音源追加のための自動一括取得はありません。
- iOSでは実操作後のみAudioContext開始。OFFを庭移動で解除せず、ページ非表示で停止。再開は本人操作。音量設定は既存値を維持。
- 自動検査はMP3デコード、波形/ハッシュ/明示ループ境界、Nodeの操作/競合/保存設定互換、全回帰、ビルド・import cache version。実ブラウザ試聴とSafari実機での聴感は本人確認。未実施を合格と扱いません。

## 本人確認
庭の音楽を「庭にあわせる」にし、庭を移動して景色ごとに変化すること、長時間のループ、連続移動、音楽OFF維持、別アプリから戻った際の操作再開を確認してください。
