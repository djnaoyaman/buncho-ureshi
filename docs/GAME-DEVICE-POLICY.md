# ゲームの対応端末・縦向き表示

2026-11-08。基点: `4910a532d38e5376ad987a95b62f73049620ee14`。
ユーザー決定: 対象はゲームだけ。スマホ・タブレットの縦向きを対象とし、横向きでは
縦へ戻す案内を表示する。対象外の端末にも「このまま遊ぶ」を残す。
図鑑・観察室・工房への制限は加えない。採用済みの画像・配色・ゲームのルールを維持する。

## 案内と起動

`src/game-environment.js` はゲームのルートだけで使う表示部品。
iPhone/iPad/Android、タッチ情報、iPadのデスクトップUAを参照する。
画面幅だけでPCを判定しない。タッチ対応ノートPCをタブレットと決めつけず、
判定できない端末には案内と続行を残す。端末の完全な識別はブラウザから保証できないため、
対象外でも利用者自身が続行できる。PCをアクセス遮断しない。

対象外ではゲームの保存を開く前に案内し、続行ボタンで通常のゲームを起動する。
初期状態では毎回案内する。「このブラウザでは次回から案内を省略する」を選んだ場合だけ、
独立した `buncho-game-device-choice-v1` キーに `continue` を記録する。
ゲーム世界や既存の設定キーは変更しない。設定の記録に失敗しても、その場の続行はできる。
対象外の環境では「暮らしの設定」の「対応端末の案内」から、この選択だけを戻せる。
ブラウザの保存全体を消す必要はない。

## 向きと画面内キーボード

通常ブラウザでは端末の回転自体を強制停止しない。物理方向が横になったときに
ネイティブdialogで案内し、縦に戻すと開いていた画面を再利用する。
ゲームを作り直さず、名前・会話の入力途中、既存のdialog、フォーカスを保持する。
方向はscreen.orientation、iOSのorientation、端末画面情報の順に参照し、
画面内キーボードによるvisualViewportの縮小だけを回転とみなさない。
ホーム画面のmanifest全体へ向きの固定を指定すると、そこから開く図鑑・工房にも
影響するため、manifestは変更せず、ゲームのルートだけに縦向き案内を適用する。

## 保存・時刻・音の保護

ゲーム世界の版11、個体ID、名前、家系、つがい、日記、墓、持ち物、Gold/Gemsは変更しない。
`engine.js` / `game-store.js` / 経済・飼育・成長の計算には変更なし。
表示中も成長と飼育の実時間は既存の一時停止・進行ルールに従う。
案内の裏で操作できない警告だけが進まないよう、既存の「見えている間だけ」の
猛禽・カラスの表示側時計へ、案内による不可視状態を接続する。
猛禽の保存済み残り時間、カラスの表示中の警告を保持し、案内を閉じても過去の時間を追いつかせない。
音は案内中に止めるが音量・曲・音OFF設定は変えず、復帰後も利用者の操作による開始を維持する。

## 検査

- UI単体: 対象外の明示的続行、任意の記憶、iPad判定、キーボードと物理方向、回転時の入力ノード保持、片付け。
- 時計・音: 案内中の警告残り時間、待機中の保存競合、警告の保持と復帰、音の停止と利用者操作による再開。
- 全Node検査: 1,490件合格・失敗/skipなし。構文365 JS、37記事・42写真・30問も合格。
- Chrome/WebKit: 新規の端末案内・起動・回転・保存一致・拡大文字の14件が合格。
- 既存のゲーム検査は、正規の「案内を省略して続ける」を選んだ状態を共有fixtureで設定。
  新規の方針検査は空の状態で起動し、初回案内も実際に検査する。既存assertionは削除しない。
- 実機の回転・キーボード・ホーム画面起動の手動確認は利用者が行う。

## 変更の分離・戻し方

最初に案内と縦向き制御、続いてタブレットの配置を別コミットで扱う。
各変更で既存の公開前CIを通し、配信ファイルを照合する。
戻す場合は新しい変更からrevertし、対応する検査・表示側時計の接続も同じ範囲で戻す。
保存形式の変更や移行は不要。既存のセーブを初期化しない。

案内と縦向き制御の最終ローカル検査: 新規14件と既存画面22件、計36件が
Chrome/WebKitで合格。Android/iPhoneの既存タッチ操作4件も合格。
全Node 1,490件・構文365 JSが合格。実利用者の保存データは使用していない。
