# 暮らしと道案内の統合リリース

4項目を1回の本番公開に統合。未実装の映画や病気・事故・死亡を達成目標にはしません。

- 既存の「次のお楽しみ」を拡張。現在の物語1件をすすめ、他の候補は折りたたみます。落ち葉・探検・発表会・お店へ既存の庭移動処理でつなぎます。
- 全4食品は無料、満腹の回復量・報酬は従来と同じ。おうちの幼鳥に限り、成功給餌で成長期間を後押しします。シード0%、ペレット4%、青菜添え2%、ごほうび添え1%を元期間から整数tickに切り捨て。実時間24時間に1回、合計最大20%。旧短成長個体では実際の短縮量を表示します。
- 世界時計・年齢・寿命は進めません。卵と雛、成鳥、来訪鳥は成長短縮対象外。家族まとめてのお世話・飼育員は従来のシードです。実際の鳥の栄養効果ではありません。
- 保存22への検証付き移行。既存個体に食事情報だけを初期化し、同一世界のインポートでは既得短縮とクールダウンを保護。旧版クライアントは新版を書き戻しません。
- 留守復帰の健康猶予とゲーム内年齢を説明。飼育員24 Gold/実日・病院12 Gold/回、契約期間・対象・自動更新なしを明記。料金/期限/死亡規則自体は変更しません。

## 検査

新規食品基幹、移行、通常/留守一致、復元、満腹連打、旧token、寿命不変の単体検査を追加。既存セーブfixtureはv21投影を共通化し、旧版の構造で引き続き検証します。

本番公開には全Node検査と `.github/browser-checks.json` のChrome/WebKit検査成功を要求します。ローカルのChrome起動は実行環境のUnix socket制限によりブロックされるため、実ブラウザ合格はPR CIで確認します。実機SafariはAGENTS.mdの運用に従い、検査済みとは扱いません。

保護baselineは pristine main `4e1ac0294e8b53409c34ee4dd9d3432fb57aad57` を別ディレクトリで再buildし、キャッシュクエリを除去して比較。意味のある既存配信差分は6ファイル（engine、game、game.css、game-next-goals、life-care-ui、caretaker-recruitment-ui）のみ。その他はキャッシュ更新のみ。新規food modulesも保護対象に追加します。
