# 出会いの図鑑の親しみ

出会った鳥のページから、今の庭に呼び戻せます。未完了のお客さまがいるときは先にその出会いを終えます。同じ鳥が同じ庭で待っている場合、繰り返し押しても回数は増えません。新しい再会は1回として記録されます。

- 出会い1回につき10ポイント。旧保存の回数をそのまま使います。
- 30ポイントで「顔なじみ」、60で「なかよし」、100で「大のなかよし」。
- イラストまたは写真を指・マウスでこすると、24pxの移動ごとに1ポイント。画像にフォーカスしてEnter/Spaceでも1ポイント。停止した指・長押しだけでは加算しません。
- 100ポイントから籠に呼べます。異種の鳥は文鳥の家系図・繁殖・お世話配列に入らず、文鳥の来訪者と合計2羽まで。
- 籠では96ゲーム時間まで遊び、次の時間に帰ります。「またね、と見送る」か「庭に呼ぶ」で先に退出できます。親しみは減りません。
- この交流・混種の訪問はゲームの創作で、実際の同居飼育の案内ではありません。

保存全体の版は7のまま、出会いの内部版を4から5へ純粋移行します。元データを変更せず、既存の回数・発見・途中の出会い・時刻・家系・通貨・乱数を保持します。IndexedDBへの内部版更新も永続化します。

検証: `npm run check`、`npm test`、`npx playwright test --config=playwright.friendship.config.js`。専用CIはChromium touch、WebKit touch、desktopの320×568・320×240・844×390・1440×900、なでる操作、招待、帰還、再読込、写真の無加工表示、キーボード、2羽上限を検証します。実機指操作と聴覚による音の確認は別です。
