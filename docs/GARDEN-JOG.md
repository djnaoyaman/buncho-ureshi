# 庭の円筒型ジョグ（35庭制作の第1段階）

既存12庭の細い選択欄を、生成りとセージ色の円筒型ジョグに変更する。背景・鳥・下部操作・庭ID・保存形式・遭遇条件・音楽再生系は維持する。

上下ドラッグ、ホイール、前後ボタン、上下左右キーで候補を回す。Home/Endは端へ移動。中央タップまたは中央ボタンのEnter/Spaceで候補への移動を確定する。停止だけでは移動しない。端は循環する。候補は再描画をまたいで維持し、確定した現在庭が変われば同期する。現在地は上部見出し、候補は中央名で区別する。

ドラッグ後のクリックを抑制し、pointercancel、非表示、ウィンドウのフォーカス喪失、画面離脱、再描画、破棄時に操作と慣性を停止する。動きを減らす設定では角度変化と慣性を抑える。候補操作から保存・訪問・出会い・BGM変更を呼ばず、確定だけを従来の世代管理付きgarden処理へ渡す。

同梱の採用デザインは形・配色の参考に使用。画像の貼り付けではなく、文字とCSSによる実装。背景画像はユーザーから別途受け取り予定。新35庭・35曲はこの変更に含めず、完成として数えない。3鳥も別案件のID・遭遇条件を重複追加しない。

検査: Node/DOMによる候補と確定、循環、Home/End、0/1件、busy、ドラッグキャンセル、破棄を検証。既存の選択ボタンを前提としたNode検査は、実際にジョグを回して確定する操作へ更新し、保存・来訪・友達・報酬の比較は残す。ビルドのバージョン付き依存に新モジュールを追加。Windowsの画像ビルドではURL.pathnameをfileURLToPathへ置き換える。

実ブラウザは依頼資料に従い起動していない。実機の回転感、文字拡大、狭幅、上下スクロールとの操作感、実際の音楽切り替えは本人確認が必要。既存CIは選択したブラウザ検査が空ならNode検査のみを要求する仕組みを使用し、必須ゲートを削除しない。

保存の追加・移行はない。戻す場合はこの変更をrevertし、保存を削除しない。
