# 庭のカラスと天敵の記録

## 遊び方

- ゲーム画面を開いて、同じ庭が表示された状態で連続120秒過ごすと、15秒ごとに20%の確率でカラスの気配が現れます。120秒ちょうどに必ず来る設定ではありません。
- 影と文章で6秒前に知らせます。おうちへ戻れば来訪は取り消し。音がOFFでも分かる視覚の予告です。
- 親しみが100未満の種が来ると、おもち（元のb1）の元気がその時点の半分になり、ほかの庭の鳥は45秒間安全な場所へ退避します。家族・関係・親しみ・図鑑・途中の出会いは削除しません。元気0は0のままです。
- カラスは18秒で飛び去り、友達は45秒で戻ります。1回の連続滞在につき1回まで、全庭共通で10実分のクールダウンを端末の保存に残します。
- 『庭の鳥図鑑 → 天敵の記録』では、遭遇前は影、遭遇後は種・特徴・全長の目安と出典が開きます。通常の友達の図鑑件数、親しみ、報酬とは別の記録です。
- 図鑑の絵をなでると種ごとの親しみが増え、100以上でその種は元気を減らさず、友達も退避しなくなります。Enter / Spaceでも操作可能。現実の野鳥に触れることを勧めるものではありません。

## 時間・保存

- 非表示タブ、別画面、家族とのふれあい画面、一時停止、オフライン、庭の読み込み未完了、別の庭への移動は連続滞在をリセットします。
- 閉じていた時間は2分に加算しません。タイマーが2.5秒以上飛んだ場合も追いつき計算をしません。
- 世界のPRNGや成長・繁殖時計とは独立。元気の変化と遭遇記録、クールダウンは既存の単一ストアのトランザクションでまとめて保存します。
- 既存の世界形式8を保持し、出会いサブ形式6以前を検査してから7に移行します。旧画面は未知のサブ形式を拒否するため古い構造で上書きしません。
- 遷移、破棄、世界の入れ替え、非表示・オフラインの割り込みは待機中の来訪を無効化します。2つのタブで同時に予告が見えても、保存時の共有クールダウンにより元気は1回しか減りません。

## 絵と縮尺

5種のために新規に作った透過イラストです。既存素材の流用や名称の付け替えではありません。原寸・足の位置・嘴先から尾先の画像上の水平幅は `CROW-ART-ASSETS.json`。

文鳥約14cmに対して、ハシブト56cm、ハシボソ50cm、ミヤマ47cm、ワタリ63cm（56〜69cmの代表値）、ズキン46cm（45〜47cmの代表値）。全長から計算した比率を共通の縮尺で表示し、画像の透明余白を補正します。文鳥の右向きポーズも実ピクセルの幅を測定し、足元を同じ線に合わせます。大きな鳥が来た場面全体の縮尺を小さくし、鳥だけ個別に最大幅へ押し込めません。生物計測標本ではなく、姿勢・個体差のあるイラストによる全長の目安です。

各種の資料リンクは図鑑内に表示します。来訪確率や退避、親しみと襲わなくなる関係はゲーム上の創作であり、現実の野鳥との安全な距離を保証するものではありません。

## 検証境界

純粋な時間計算、保存互換、0エネルギー、友達と家族の保持、2タブ、親しみ100、画面遷移、失敗した保存、連続なで、キーボード、非表示の割り込みを単体・DOMテストで検査。実Chrome/WebKitの画面・同じ足元・320px/短い横画面・影を見て戻る流れは専用CIで検証し、結果確定前に公開済みとはしません。
