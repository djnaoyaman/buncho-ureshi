## 利用の約束

- 写真はすべて実写。生成画像を図鑑写真として使用していません。おもち本人の写真は未提供です。すべて一般の資料写真として表示します。
- 写真の加工: 長辺1200px以内への縮小とWebP変換のみ。色補正・切り抜きなし。画面の CSS crop はレイアウト用で、別写真として数えません。
- 写真・動画は各ファイルのライセンスのまま再配布します。サイトのコードのライセンスは素材に適用されません。
- CC BY-SA 写真は図鑑専用（artAllowed:false）。保存作品用は CC BY または CC0 の26点だけに限定。改変・切り抜き・共有が可能なライセンスであり、必要な帰属とライセンスURL、改変表示を保存画像へ含めます。
- photo-03 は CC BY 4.0 ですが、正確なジャワ文字の作者名を全端末のCanvas書き出しで表示できる保証がないため図鑑専用。未確認のローマ字表記へ置き換えません。
- 著作者名・元ファイルURL・ライセンス・ライセンスURL・加工内容は src/data/photos.js に機械可読で保持。外部直リンク依存ではなく public/photos に保存。
- 写真から感情、性別、病名、家族関係を推定してキャプションへ断定しません。野外の写真を理想的な飼育環境の見本にしません。
