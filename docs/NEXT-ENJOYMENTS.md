# 次のお楽しみ

暮らしのメニューに、閉じた状態の「次のお楽しみ」を追加する。ユーザーの指示に基づく
出会い・友好・収集・家族の次の楽しみの案内。既存の記録から毎回読み取り、
新しい目標・報酬・期限・達成フラグ・保存形式は追加しない。

- 出会いは既存図鑑の発見済み数。未遭遇で待機中の鳥、現在の庭の鳥、図鑑順の鳥の順で
  ひとつの手がかりを選ぶ。未遭遇の名前は出さず、既存の探索ヒントを使う。
- 友好は発見済みの鳥のうち100ポイント未満で最も近い友達を選ぶ。
  既存の親しみ値から残りを表示し、その鳥の記録へ進む。
- 収集は既存9カテゴリ×8色×3仕上げの所持数。現在解放されている仕上げで
  未所持があるカテゴリへ案内する。全部そろっていれば装飾や次の解放を楽しむ案内にする。
- 家族は現在の主人公の世代と、生存中で家にいる卵・ひな・幼鳥の次の成長段階。
  成長中の子がいなければ家族の記録へ案内する。世代交代や死亡を目標にしない。

提案は新しい物語の予告や出会いの保証ではない。確率・友好・通貨・成長期間・血縁・
日記・墓・乱数列を変更せず、リンクを開くだけでは保存を書き換えない。
既存のメニューボタンと混同しない専用のdata属性を使い、既存画面へ移動する。
披露内容は現在の記録から選び直し、閲覧・再読込で報酬を付けない。

単体検査は初期・発見待ち・友好が近い鳥・全部達成・次の解放・成長・文字のエスケープと
世界全体の不変性を確認。画面連携は4つのリンクの遷移と保存全体の一致を確認する。
Chrome/Safari互換WebKitは320pxと拡大文字で、初期と既知の友達・育成中の子がいる
合成保存を使用し、読みやすさ・遷移・再読込後の保存一致を確認する。
ゲームのキャッシュ識別子には新モジュールも含める。
