
## 35羽の出会い・再会（次の公開）

`GARDEN35_PLAN.birdId`を各庭の固有鳥の出会い先に使用する。
追加はヒノマルチョウ、マスクフィンチ、ズグロヒワの3羽。文鳥の主人公・家族は別枠で、鳥図鑑の訪問者は35項目となる。
庭に入るだけでは発見せず、図鑑の目撃ヒントと同じ観察を行い、既存3段階の会話を完了して発見する。再会も同じ庭・同じ観察で可能。従来の3観察・8tickの再会待ち時間を維持する。
旧32羽のID・会話のaction/段数・発見・親密度・招待と、既存18羽の文鳥常連を保持する。旧庭で途中だった会話はその場所で完了し、新しい固有鳥は会話終了後だけ登場する。おうちにいる鳥は庭へ同時出現させない。
固有鳥の1対1対応とは別に、親密度60以上の鳥の他庭への自然訪問と、手動の「庭に呼ぶ」を既存通り維持する。訪問開始時の親しい鳥リストを使い、途中の操作で訪問者候補を入れ替えない。
3羽の資料写真は最初の引継ぎZIPの無加工原版を使い、SHA-256と個別ライセンス・撮影地/日付・クレジットを検査する。画像は承認済みWebPのまま使用し、体格・足元の全35羽調整は次の段階。実機の見え方は本人確認待ち。
