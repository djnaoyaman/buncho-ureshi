# 35庭・35羽への移行

更新 2026-11-13 日本時間

## 今回の背景接続

35枚を `public/game-art/gardens35/` に接続。01は実景参考の承認済み梅島公園、02〜35は受領したWebPの元バイトを維持。寸法とSHA-256は `src/data/garden35-assets.js` に記録。
世界の保存版16を維持し、encounters版14へ更新。旧12個の訪問回数を保持し、新23個を0で追加する。固定した公開前保存の全世界比較と旧バリデータ拒否を検査する。
背景は現在の庭の1枚だけを読み、35枚の初回一括取得はしない。足元・coverは数値検査済みで、実機の表示は未確認。
この段階では従来の出会い条件と18羽の文鳥常連を維持する。一庭一羽・不足3鳥・体格・個別曲は別の公開。新23庭の専用曲は未接続のため既存の曲を継続し、音量・OFF・固定曲の設定を保持する。

## 前回の基礎公開

35庭・35羽・紹介文・音楽の方向性を `src/data/garden35-plan.js` に固定する。
文鳥は主人公・家族として扱い、スズメの庭を「足立区梅島公園」とする。
21番は「落ち葉の小径」。フラメンコ風とボサノヴァの指定を保持する。
確認用の `/garden35-plan/` は静的ページで、保存や発見・訪問を書き換えない。
ゲームの庭はまだ12件、世界の保存版16・encounters版13を維持する。
`prepareGarden35Visits` は移行用の訪問回数を準備する純粋関数で、実ゲームからは未呼出し。

## 保存を守る設計

旧12庭のIDを新35庭の一部へ引き継ぎ、23個のIDだけを追加する。
名前や背景の変更を、保存済みIDの置換と混同しない。
この方法では既存の庭ID参照、訪問回数、会話、思い出、天敵の庭IDを再採番しない。
対応表の `legacyId` は一意で、旧12件をすべて含む。
新IDは鳥IDから決め、表示順や配列の番号では保存しない。

実際の切替時は、旧スキーマで検証した後にencounters版を更新し、新しい23個の訪問回数を0で追加する。
旧版は不明な版・追加キーを拒否して保存を上書きしないことを、固定した旧エンジンでも検査する。
この公開の検査では旧エンジンが35個の訪問キーを拒否すること、旧世界が変わらないことを確認する。
未知のキー・欠損・不正な値・アクセサーを修復せず拒否する。

旧12庭の常連の名前・親しみ・思い出・知人参照を削除しない。
一庭一羽の新しい出会いへ切り替えるときも、途中の会話は完了まで保護し、同時に別の住人を発生させない。
家族・主人公・持ち物・通貨・図鑑・不在ケア・乱数列は移行で変更しない。
保留中の会話、天敵イベント、招待・同行、訪問スナップショットを持つ保存について追加の統合検査を行ってから有効化する。

## 分割手順（1・2は今回実装）

1. 足立区梅島公園の実景を確認し、専用の背景・紹介を制作する。棚田画像を公園として公開しない。
2. 35背景を個別確認して接続し、画像寸法・足元・切り取り・読込世代・先読み範囲を検査する。
3. 3羽の不足登録と、一庭一羽の出会い・再会を有効化する。自動発見させない。
4. 35羽の体格と足元を庭・おうちで揃える。
5. 専用曲の方向性確認・制作・接続。完成までは既存BGMと音量設定を維持する。

各デプロイ成功時に公開URLと本人の実機確認項目を伝える。
実ブラウザは起動しない。Node/DOM・画像のオフライン検査・HTTP照合を行い、実機の見え方・操作感は未確認と記録する。
