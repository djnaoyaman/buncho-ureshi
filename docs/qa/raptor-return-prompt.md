# 猛禽の帰宅確認（2026-11-13）

## 承認された変更
危険な猛禽の来訪で「おうちに かえりますか？」を表示。
「おうちに かえる」を第一選択にし、即帰宅。「にわに のこる」の明示選択後だけ既存の残り時間を進める。
質問を読む時間は危険時計から除外。既存の親しみ、事故条件、カラス、友好的・非攻撃の来訪は変更しない。

## 保存と操作
- encounter v14 → v15。既存警告の対象・残秒・訪問履歴を保持し、選択待ちだけ追加。
- 時間停止は保存状態で制御し、DOMの有無に依存しない。
- 再読込・隠れたタブ・保存失敗で残秒を取り戻したり、読み時間を後払いしない。
- 「残る」を選んだ事実も保存。再読込で同じ質問を繰り返さない。
- Escapeは帰宅。背景クリックに暗黙の残留を割り当てない。
- 二重入力を抑止し、保存失敗時は選択待ちのまま再試行可能。
- 状態の別タブ更新・なかよし化・帰宅・別worldで不要になった質問を閉じる。
