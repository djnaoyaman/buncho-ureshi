# 平地型の個体別描画（型①）

対象は基準 #01 足立区梅島公園と、#03/#04/#06/#11/#15/#20/#21/#26/#29/#31 の10庭。次の型、未公開 #255、新しい庭・鳥は含まない。

## 素材と境界

承認済み `umejima-bird-life-four-colour-flight.html`、Library `libfile_fde3_f-c411323183088191a0da843b56b9ee19_1e5190e96ae0819195a4cad3042d859b` v0（6,124,653 bytes、SHA256 `04cd0cbddfa0307473a15ebdee5dc1205131679b1570afadb12d4181f9aa3c38`）の4色の元画素と部位クリップを利用。白い翼の黒縁修正は外縁アルファだけ。桜・シナモン・シルバーの目・嘴・脚を含め全体色フィルターは使わない。公開画像ファイルは変更しない。

既存の滞在一覧が個体の権威。4人の常連、最大4羽の同行個体、庭のお客様と再訪客の計10羽を扱う。個体IDのMapはDOM再描画をまたぎ、来訪・帰宅では該当IDだけを追加/除去する。実在の来訪・帰宅・天敵抽選を演出側で発生させない。文鳥以外のお客様の絵を文鳥の飛翔に置き換えない。

`garden-actor-state.js` は世界・保存・ゲームの乱数にアクセスしない。状態が終わる時に実行可能な移動候補を先に絞り、従来承認見本の重みで休む/見回す/ついばむ/羽づくろい/小跳び/飛翔を選ぶ。個体の間、飛翔後の8秒休止、近傍だけの遅延反応を持つ。現行の同行代表だけは初回に安全な飛行候補を優先する。初期配置でその個体を閉じ込めず、後から来た個体のために他個体を並べ替えない。

着地点の予約を先に取得し、出発点も着地まで占有する。近隣反応の実行時に対象の存在と距離を再確認。進路の変更は新しい着地点を確保した後、位置と一次速度をつないだ曲線を使う。画面形状の変更で切り抜き範囲から外れた経路は通常の飛翔と区別して安全な接地配置を再計算する。全画面回転中まで同じ飛行曲線を保証するものではない。

## 庭ごとの設定

`src/data/garden-actor-terrain.js` の座標は既存原画の正規化座標。既存のcover投影後の寸法を読む。地形を同じ矩形で複製せず、幹・花・根・草・段差を各原画で確認してポリゴンと候補足場を定めた。選択した低い地表には前景マスクを新設せず、植生へ入る経路を認めない。庭名、元背景、曲紹介は変更しない。

背景/地表の影/鳥/既存UIを分け、足元の奥行きで描画順を決定。鳥の全画像箱の一律分離ではなく部分重なりを許し、実ボタンの中心タップを守る。飛行中は絵とボタンが同じ高度に移り、名前札のみ隠す。既存1本のrAFが全個体を更新する。計測後に描画し、経路判定中の他個体の軌道計算は一度だけ行う。
