# 出典と編集方針

確認日: 2026-11-02。37項目・30問。本文は出典の内容を踏まえた独自の短い教育用解説です。長い転載・翻訳、元記事の画像転載はしていません。写真の権利は別途 ASSETS.md を参照してください。

## 情報の区別

- 文鳥の一般情報、鳥類に共通する仕組み、ご家族から確認したおもちの情報、ゲームの創作を区別する。
- Padda oryzivora と Lonchura oryzivora は資料によって使われる学名。羽色の「白」「桜」「シルバー」は種名ではない。
- 原産地はジャワ島・バリ島を中心として記述。BirdLife はマドゥラ島も可能性を挙げるため、ジャワとバリだけに絶対限定する表現は避けた。
- 国立環境研究所の古い絶滅危惧区分（VU）は採用せず、BirdLife の現行種ページで2021年評価 EN を確認。確認時点の資料の評価である。
- 弥富の白文鳥史は伝承を含むため「と伝えられる」と表記。環境省の旧マニュアルは羽色の呼称確認に限定し、古い食事・保温・繁殖方法の推奨には使わない。
- Eindhoven Zoo の体重表は本文と数値が一致しないため採用せず、くちばしの機能の一般説明だけを参照。
- 耳の方向定位研究はカラス・カモ・ニワトリを対象とし、文鳥で直接実験したとは書かない。
- 家庭の食事を数値割合で一律に指定せず、食事変更、繁殖、体調不良は鳥類診療の獣医師への相談を勧める。診断・投薬・ひなの強制給餌手順は掲載しない。
- AAV睡眠記事は検索結果で要点を確認したが、本文取得は403だった。時間数など未確認の詳細は採用せず、静かで妨げられない睡眠と獣医師相談の要点のみ。別途 University of Florida の睡眠環境説明で照合。
- 「観察」「質問帳」の方法・問いは編集部の教育用提案で、実在のおもちの出来事や娘さんの発言ではない。
- おもちの年齢・誕生日・性格・好物・日記・実写写真は未提供。別の文鳥を本人として掲載しない。

## 更新方法

1. src/data/articles.js の各項目は summary（まず見る）、body（基本）、deep（もっと調べる）、terms、sources、related、mission、checkedAt を持つ。
2. 日本語の ruby は本文に限定。本文の読み上げ時は rt を除去し、文字が二重に読まれないようにする。
3. クイズは src/data/quizzes.js。answer は choices の0始まり位置。articleId は必須、photoId は任意。答えの解説と関連記事の根拠を揃える。
4. 写真を追加する前に、作者・転載と加工の権利・共有条件・個体同定を確認。写真自身をローカル保存し、photos.js と ASSETS.md を更新する。
5. おもち本人の写真を公開する場合は、写真ごとの公開許可と権利者・撮影日・本人確認を先に確認する。現在、本人の実写写真は非公開。参考画像の提供だけを公開許可と扱わない。一般写真を本人として説明しない。
