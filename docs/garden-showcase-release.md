# 第3回 庭の発表会と小さなお店

落ち葉のおくりものを終え、探検を1つ以上持ち帰り、常連2羽と交流すると入口から遊べる。3テーマ（歌・見つけたもの・おしゃれ）は参加費・時刻・順位なし。鳥2羽の好み、過去の落ち葉と探検を会話と舞台に反映する。

- 各テーマ初回の記録を日記に残す。全3テーマ初回達成で最大5 Gemsを1回のみ。繰り返しは報酬なし。家族・野鳥の親しみ、繁殖、寿命には影響しない。
- 店はベル・飾り枠・リボンの3品、各6 Goldまたは対応する探検の発見柄で交換。記念絵札は消さず、柄を使ったことのみ記録する。永久所持、買い直し・売却なし。所持品は発表会の演出を変えるが報酬増加はない。無料・無装飾ですべて達成可能。
- 価格は1日のGold30/飼育員24と比較し3品合計18。最大Gems5は最安ガチャ20の1/4、繰返し収入なし。全3探索を既に終えていれば全品をGoldなしで交換可能。
- v19へ任意のshowcase記録を追加する。既存保存は初期化せず、そのまま読み取る。最初の有効な発表/購入でのみ項目を追加し、world/revisionの確認と既存単一トランザクションで通貨・持ち物・記録を同時保存する。
- 旧アプリが新項目を含む保存を読むことはできないため、変更後は新しいページを再読み込みする。旧版へ戻す際にshowcaseを無断削除しない。
- 閉じる・Escape・別庭・中断からの復帰を維持し、天敵/既存遭遇中は発表進行を抑止する。ゲーム外のサイト本文・デザインは変更しない。
