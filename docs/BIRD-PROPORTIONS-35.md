# 35羽の見た目の体格と足元

対象: 庭に現れるお客さま、おうちに来た友達。図鑑の原画表示と保存データは変更しない。

- 採用済み画像35枚を一覧で確認し、頭頂・立ち足・足の左右中心を設定。
- 文鳥の立ち姿を基準にした見た目の比率。頭から足までを基準とし、尾や透明余白を身長に含めない。
- 小型フィンチは0.78〜0.9、大きいシメ・イカル等は1.18〜1.3。数値は創作画像を読みやすく並べる調整値で、実寸・生物学的な縮尺ではない。
- `src/encounter-body-art.js` が庭とおうち共通の設定元。新しい鳥を増やす際は画像・頭頂・足・比率の確認を要する。
- 庭の枠は文鳥と同じ大きさ、混雑時は44px以上の操作対象を維持。
- 長尾2羽は旧頭頂/足測定を保持。尾が操作部へ被らないよう、足元より下の画像領域を余白計算に含める。
- 元画像、図鑑写真、名前・親密度・訪問・保存移行・乱数列は変更しない。

検査: 全35画像の目視、画像からの座標計算、全35羽の庭/おうちDOMとCSS、長尾の下端余白、全Node回帰と構文検査。実ブラウザ・スマホ実機・実際の重なりの最終確認は未実施、本人担当。
