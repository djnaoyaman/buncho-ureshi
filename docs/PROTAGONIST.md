# 主人公の代替わり

## ルール

- 最初の主人公は保存ID `b1` のおもち。名前や選択中の文鳥では判定しません。
- 現在の主人公が旅立つと、その主人公の存命の実子のうち最も先に生まれた子が引き継ぎます。性別で優先順位は変えません。同じゲーム時刻に生まれた場合は、生まれた順のIDで決めます。
- 死亡判定は全員分を済ませてから候補を選びます。同じ更新で亡くなった子に一瞬だけ引き継ぐことはありません。
- 最年長の子が卵の場合は、その子の孵化を待ち、ひなから主人公になれます。お出かけの姿は従来どおり幼鳥・成鳥から表示します。
- 存命の実子がいない場合だけ、健康・思い出の庭・家族画面から残っている家族を選び、確認して引き継げます。今の家族と、誕生・お迎えの記録がある独立済みの家族が候補です。普通の来訪者は候補にしません。
- 候補が卵なら孵化後に改めて選びます。外で暮らす家族の帰宅には家族6羽の枠が必要で、空くまで選択できません。予約・自動選択・誰かの追い出しはしません。選択時に全員の実時間の期限を確認し、すでに旅立った候補には引き継ぎません。
- 家族がいない場合はその状況を表示し、家系・お墓・持ち物・メニューを残します。主人公を埋めるための鳥の生成、復活、リセットはしません。通常の友達の来訪など既存の遊びは続きます。
- 巣立った子が最年長なら、同じIDのまま帰宅して引き継ぎます。家族が6羽の場合は空きを待ち、誰かを追い出しません。帰宅から給餌の期限を数えます。外で保留されていた病気の期限が過ぎている場合も病気は治さず、見える通院時間を1日確保します。
- 次の主人公が亡くなった場合も、その子の最年長の存命の子へ同じ規則で引き継ぎます。実子がいない場合に限り、再び家族から明示的に選べます。
- 現在の主人公とそのつがいは、自動の巣立ちで家を出ません。庭の主役と「自分＝名前」の星印は、どの鳥を選択していても保存された主人公に付きます。

## 残るもの

先代のID、名前、血縁、つがい、思い出、お墓と祈りの回数は残ります。Gold、Gems、持ち物、家具はそのまま。日記に代替わりを一度だけ記録し、歴代主人公のIDを保存します。無料で起こるゲーム内の出来事で、通貨の支払いや報酬はありません。

## 保存形式 v10

`protagonist` は `{version:2,birdId,lineage,familySelections}`。`lineage` は `b1` から始まる重複しない歴代主人公のIDで、最後が現在の主人公です。実際の親子情報や血縁上の世代は書き換えません。

利用者が選んだ実子以外への交代は、`familySelections` に `{fromId,toId,tick,at}` を残します。日記の240件上限で出来事が消えても選択履歴は残ります。各記録は歴代の隣り合うID、先代の死亡時刻、誕生・選択の時刻、残っている日記と照合します。`at` は実時間の健康時計で、物語時計の日記日時とは別です。選択後に家族が亡くなっても、当時の選択を失いません。

v1〜v9は各版を検証後に移行します。v9からは主人公情報の版と空の選択履歴を追加するだけです。健康・実時間の期限・財布・家族・過去の出来事を変更せず、誰も自動で選びません。v8以前からの移行も同じ追加移行を通ります。最初の通常更新で全員の死亡判定を終えてから、従来の実子への代替わりを行います。

保存キー、IndexedDBのトランザクション、古い画面のrevision/worldId保護は維持。v9以前の古いクライアントはv10を上書きできません。明示的な保存全体の復元では、その保存の主人公・歴代・死亡状態を復元し、今の庭と混ぜません。選択日時は過去の記録として移動しません。実利用者のデータを検証やリセットに使いません。

## 検査

`tests/protagonist.test.js` は出生順、男女、同時死亡、孫への継承、子なし、孵化、帰宅、定員、旧保存の期限、読み込みの競合、破損保存、復元、9つの庭を検証します。

`playwright.protagonist.config.js` は Chromium touch / WebKit touch / desktop の42ケース。本人印、先代の墓、祈りの保存、操作中の代替わり、3代目、子なし、v8移行、画面の狭幅・広幅と再読込を確認します。home-visitsの26検査では本人の改名・同名家族・他の鳥の選択、満員時の病院通知・墓への導線も確認します。

家族選択は `tests/family-successor.test.js` と `tests/family-successor-ui.test.js`、専用ブラウザ設定に含まれる `tests/browser/family-successor.spec.js` で検査します。取消・Escape、期限切れ・別タブ更新、孵化待ち・満員、空の家族、再読み込み、日記の切り詰め、旧保存と復元を含みます。
